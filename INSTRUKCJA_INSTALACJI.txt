1. WYMAGANIA


Przed instalacja upewnij sie ze masz:

- Docker 
- PHP w wersji 8.4 lub nowszej
- MySQL w wersji 8.0 lub nowszej  
- Co najmniej 2GB RAM
- Co najmniej 1GB wolnego miejsca na dysku


2. INSTALACJA KROK PO KROKU


Krok 1: Przygotowanie plikow


Skopiuj wszystkie pliki projektu do folderu na swoim komputerze.


Krok 2: Instalacja zaleznosci

W terminalu wpisz docker compose up -d

Krok 3: czyszczenie mysqldata

sudo rm -rf docker/mysqldata

Krok 4: Utworzenie tabel w bazie danych

php artisan migrate::fresh --seed

Krok 4: 

w katalogu projektu
docker compose exec app bash
npm run build
